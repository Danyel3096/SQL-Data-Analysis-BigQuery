# 📊 Análisis de Datos a Gran Escala con Google BigQuery, SQL & Python
## 🎯 Objetivo del Proyecto
Este repositorio contiene una serie de proyectos con casos prácticos enfocados en la extracción y manipulación de datos masivos (Big Data) utilizando la infraestructura de Google Cloud (BigQuery). El objetivo es demostrar habilidades avanzadas en SQL y la integración con Python para resolver problemas de negocio complejos.

## 🛠️ Herramientas Utilizadas
**Lenguajes:** SQL (Standard SQL), Python.

**Librerías de Datos:** google-cloud-bigquery, pandas.

**Plataforma Cloud:** Google BigQuery (Datasets públicos: Chicago Crime y Hacker News).

## 🚀 Habilidades Técnicas Demostradas
Cada notebook en la carpeta notebooks/ aborda una competencia clave para el análisis de datos moderno:

1. **Gestión de Infraestructura Cloud:** Configuración de clientes API, manejo de cuotas de datos (QueryJobConfig) y exploración de esquemas de tablas masivas.

2. **Filtrado y Limpieza:** Aplicación de lógica condicional (SELECT, WHERE) para extraer información relevante de millones de registros.

3. **Agregaciones de Negocio:** Uso de GROUP BY y HAVING para generar resúmenes estadísticos (contar crímenes por distrito, identificar usuarios más activos, etc.).

4. **Optimización de Consultas:** Implementación de CTEs (Common Table Expressions) con la cláusula WITH para escribir código SQL más legible y eficiente.

5. **Relacionamiento de Datos (Joins):** Cruce de tablas complejas para unificar fuentes de información dispersas.
